接続設定

GitHub の Personal Access Token を使って、このリポジトリの投稿キューを読み書きします。 トークンはこのブラウザの中だけに保存され、どこにも送信されません （GitHub API を除く）。

Fine-grained token を、このリポジトリだけに絞って Contents: Read and write の権限で作ってください。 作成ページを開く

投稿の校正に使います。空のままなら校正ボタンは出ません。 キーの作成ページ で専用のキーを作り、利用上限を設定しておいてください。 GitHub のトークンと違い、キー自体に使える範囲の制限がかけられません。

Google Apps Script を Web アプリとして公開し、その URL を入れます。 合言葉はスクリプト側の SECRET と同じ文字列にしてください。 空のままなら「記録」ボタンは出ません。

記録する

思いついたことを、そのままネタ帳に書き足します。整える必要はありません。 ここに溜めたものが、翌日の投稿の材料になります。

ネタ帳の「## 紹介する商品」に - 商品名 | URL | メモ の形で書き足します。 12:00 の枠だけ、まだ紹介していないものが上から順に選ばれます。

メモに書いた範囲のことしか投稿になりません。 「軽い」だけでなく「重い三脚は結局出さなくなる」まで書くと、投稿が具体的になります。 合わない場面も一言書いてください。良いことだけ並べると読まれません。
